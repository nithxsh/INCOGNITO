## 🛡️ Active Security Shields

This portal is locked down with client-side and server-side defensive shields:
1. Anti-XSS Sanitization: Automatically sanitizes user forms to strip malicious scripts and HTML tags before transmission.
2. Anti-Data Scraping Shield:Detects automated browsers (Selenium/Playwright/Puppeteer) and instantly blocklists bot sessions.
3. Intellectual Property Shield: Standard right-clicks and developer hotkeys (`F12`, `Ctrl+Shift+I`, `Ctrl+U`) are locked down with custom HUD notification alerts.
4. Firestore Security Hardening: Restricts all read/update privileges to keep user information fully encrypted and inaccessible to the public.
